> The default theme of Maemo Leste: Nokia's Nseries look for Hildon, drawn with the sapwood engine.

This package is the look of the Hildon UI: the GTK rc file and the 470 images the sapwood engine tiles into buttons, menus, entries and title bars. Install the Hildon UI package first.

It is GPL-3.0 (Maemo Leste's repository); the rc file and artwork are Nokia's, Creative Commons Attribution-ShareAlike 2.5. The package installs both licence texts and the source offer in `\resource\hildon-theme-alpha\licences\`.
